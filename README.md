# PROJETO-FINAL
Estudo de Caso 1 – Sistema de Comandas para uma Lanchonete
A Sabor da Orla é uma pequena lanchonete localizada à beira-mar, conhecida por seus sucos naturais, sanduíches, saladas de frutas e outros alimentos leves.
A lanchonete possui várias mesas para atender os clientes que frequentam a orla. Atualmente, os pedidos são anotados manualmente pelos atendentes em comandas de papel.
Com o movimento do estabelecimento, o proprietário percebeu que esse controle pode causar dificuldades. Os atendentes precisam saber quais produtos foram pedidos por cada mesa, quanto os clientes já consumiram e quanto ainda falta pagar.
Por isso, o proprietário decidiu desenvolver um sistema para auxiliar no controle das mesas, cardápio, pedidos e pagamentos.
Antes de registrar pedidos, os produtos disponíveis na lanchonete deverão fazer parte de um cardápio previamente cadastrado. Para cada item, deverão ser informados dados como seu nome e preço.
Quando um grupo de clientes chegar, o atendente poderá abrir uma mesa para iniciar um atendimento.
Durante o atendimento, os clientes poderão realizar vários pedidos. Para registrar um pedido, o atendente deverá escolher um dos produtos existentes no cardápio e informar a quantidade desejada. O sistema deverá utilizar o preço cadastrado para calcular o valor do pedido.
Uma mesa poderá receber vários pedidos durante o atendimento.
O atendente também deverá poder consultar a comanda de uma mesa, verificando os produtos pedidos, suas quantidades e o valor acumulado.
Como uma mesa pode possuir vários clientes, o pagamento poderá ser realizado em partes. O sistema deverá permitir registrar diferentes pagamentos e acompanhar quanto já foi pago e quanto ainda falta pagar.
Quando toda a conta estiver quitada, o atendimento poderá ser encerrado e a mesa deverá ficar novamente disponível para outro grupo de clientes.
Neste primeiro momento, o cenário não considera controle de datas, horários ou histórico de atendimentos encerrados. O foco está no controle dos atendimentos que estão acontecendo.
Fluxo principal
cadastrar cardápio → abrir mesa → registrar pedidos → consultar comanda → registrar pagamentos → acompanhar saldo → encerrar mesa
